# State Migration Coercion Module v0.1

## Question

The module assesses claims that a state deliberately permits, facilitates, redirects or amplifies cross-border human movement to pressure another state.

It also requires examination of:

- organic mobilisation;
- forced displacement and humanitarian need;
- administrative or command failure;
- criminal facilitation;
- mixed organic and deliberate causes;
- third-state encouragement or direction;
- insufficient information.

## Evidence architecture

The module covers:

1. border-enforcement baseline and deviation;
2. command and control;
3. transport and logistics;
4. mobilisation networks;
5. diplomatic context;
6. timing and sequence;
7. restoration of control;
8. financial or operational links;
9. humanitarian and economic drivers;
10. third-state contacts.

## Stronger evidence

High-value evidence includes authenticated orders, operational records, source-independent observations, transport or payment records, original mobilisation material and communications linking an actor to an event-specific decision.

Motive, hostile statements and convenient timing remain weak without bridge evidence.

## Historical library

The initial library contains six public comparison records:

- Belarus and the European Union's eastern borders, 2021;
- Morocco and Ceuta, 2021;
- Turkey and the Greek border, 2020;
- Finland's eastern border with Russia, 2023–2024;
- forced displacement from Ukraine, 2022;
- Mediterranean refugee and migrant movement, 2015.

The cases are deliberately classified differently. The library does not treat official statements, parliamentary findings, sanctions, contested claims and humanitarian data as equivalent forms of proof.

## Boundary

The library should guide comparison and research priorities. It must not be used to say that a new event is probably coercive merely because it resembles a historical case.
